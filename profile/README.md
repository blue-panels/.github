# blue-panels

Programs for the terminal that continue GNU Midnight Commander.

### [mcommander](https://github.com/blue-panels/mcommander)

A file manager that continues GNU Midnight Commander: two panels, archives as
directories, connections to other machines, a built-in terminal, Lua plugins,
and sessions that outlive a closed terminal or a dropped ssh connection.

### [bluerig](https://github.com/blue-panels/bluerig)

A terminal IDE grown out of mcedit, the editor of Midnight Commander: language
servers, the tree of a project with its build and debugger (gdb and debug
adapters), a Git window, and queries of PostgreSQL and MongoDB.

![bluerig](https://raw.githubusercontent.com/wiki/blue-panels/bluerig/assets/overview.gif)

The two work together: the Git, MongoDB and PostgreSQL panels of mcommander
open bluerig, and F4 can open files in it.
